# Mode: Inbox

`Inbox.md` at the vault root is the single inbox: the user drops anything into it in any form
(thoughts, links, videos, articles, books, code). This mode sorts the inbox and files the material
into the vault.

Not the `video` skill: there the input is one video link; here it is an accumulated list of mixed items.

## For each item

1. **Topic.** Decide what it belongs to (`vault-map.md`).
2. **Is it covered already?** Check the map (MemPalace) and the files. Do not judge by file name:
   read both notes and look at incoming links before calling something a duplicate.
3. **Decide:**
   - no topic or note: create it (the Note process, from a seed or from scratch);
   - the note exists and the item adds something: add what is missing, in the right place;
   - already covered: do not duplicate.
4. **Remove the item** from `Inbox.md` once it is filed: the inbox must empty.

## Rules

- **One item at a time.** Each item has its own topic and links; a mixed context hurts both.
- **A video link** goes to the `video` skill; **a PDF** to the `pdf` skill.
- **A book** goes to Book mode.
- Dictionary, cards, sources and the map update: as in ordinary Note mode.

## Report

At the end, briefly: what went where, what was created, what already existed.
