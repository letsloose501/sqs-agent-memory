# Vault map

The map of this vault: top-level topics and what goes where. The `notes` skill reads it before
filing a note and adds a line when it creates a new top-level topic. Rename or translate the
folders freely; then update this file, since it is the authority.

| Folder | What goes there |
|---|---|
| `Programming/` | code, languages, algorithms, git, databases |
| `Media/` | video, editing, design, music, writing for an audience |
| `Education/` | philosophy, psychology, languages, maths, history |
| `Self-development/` | habits, productivity, learning, health, speech, sport |
| `Books/` | one note per book, grouped by category |
| `Dictionary/` | one note per word family; every topic links its terms here |
| `Cards/` | spaced-repetition decks, mirroring the topics |
| `Ideas/` | things you want to build: one file per idea, not study notes |
| `Videos/` | the registry of processed videos (`Processed.md`) and the queue (`Queue.md`) |
| `PDF/` | the registry of processed PDFs (`Processed.md`) |
| `Inbox.md` | drop anything here; "sort my inbox" files it |

Conventions: the foundation of a big topic goes into `<Topic>/Basics/`; a file name is how you will
link to it; one note owns each concept and the rest link to it.
